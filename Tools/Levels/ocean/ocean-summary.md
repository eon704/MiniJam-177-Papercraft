# Океан: 10 + 3 уровня

Это полный мир «Океан» в `.pbl`, собранный по схеме Леса. Основа — течение и плот. Прилив есть только в уровне 06.

Вид механик Океана в игре сделан заглушками (`Assets/Scripts/Biome/OceanView.cs`, не скомпилировано в Unity). Импорт `.pbl` принимает течение и плоты; уровень 06 с приливом импорт пока отклонит. Все уровни проверены командой `LevelReport check` на правилах по умолчанию, ошибок валидатора нет. Пробные уровни этапа 3 и вердикт по механикам лежат в `probes/`.

| Уровни | Содержание |
| --- | --- |
| 01–03 | Вводные: течение поворачивает лодку; плот сдвигает лягушку на клетку; плот перевозит журавля через протоку. Прощение 50–100 %. |
| 04–07 | Развитие: плот по расписанию (успеть к причалу), лодка на плоту, прилив (06), плот, который течение подгоняет к лодке. |
| 08–09 | Встреча с Лесом: кувшинки и листок (08), хрупкие клетки (09). |
| 10 | Финал 7×7, собран конструкцией из трёх задач: поймать плот первым ходом → течение с поворотом → кувшинка, назад только лягушкой. |
| Б1–Б3 | Бонусы: запаса нет, решение единственное. Б1 — плот по расписанию (10 ходов), Б2 — лягушка дважды ловит плот (8 ходов), Б3 — течения без плота (9 ходов). |

Требования штаба и как они выполнены:

- Прощение вводных не ниже 50 %: 50, 100 и 100 %.
- После вводных прощение между соседними уровнями падает не больше чем вдвое: 50 → 33 → 25 → 20 → 25 → 17 → 20 %.
- Мёртвых клеток 0 во всех 13 уровнях.
- Прилив в одном уровне из трёх разрешённых.
- Поездка на движущемся плоту (колонка «На плоту»: ходов на плоту в решении; «обязательно» — решатель не находит 3★ без поездки): основные 02, 03, 04, 05, 07, 10 (6 из 10), бонусы Б1 и Б2 (2 из 3).
- Неподвижных плотов нет. В 04, 06, 08 и прежнем Б1 плот стоял островком: 04 и Б1 переделаны, в 06 плот заменён кувшинкой, в 08 — кувшинкой и сушей; решения и метрики 06 и 08 не изменились.
- Течение нужно в каждом уровне с течением: без него 3★ получаются иначе или не получаются.

Ограничения, о которых стоит знать:

- Финал (20 %) прощает чуть больше, чем 09 (17 %). Отрезков у него три, и каждый открывается одним ходом; ловушки есть (ход журавлём вместо прыжка на плот, кувшинка справа), но первые два хода развилок дают мало.
- В 03, 04 и 10 звёзды лежат на единственном пути к финишу (финиш/3★ = 1.00): дойти до финиша без звёзд нельзя.
- Вводные 03 и 04 — только журавль (плюс одна лодка в 04): механику плота показываю без смены форм.
- Б2 — 8 ходов, остальные бонусы 9–10.
- Прощение вводных посчитано на малом числе первых ходов (1 из 1, 1 из 2).

### ocean-01

идея: знакомство с течением: лодка входит в струю, и течение поворачивает её к звёздам и к финишу, до которого по прямой не доплыть

```
##>E#
##*w.
##w##
S~.##
```
Решение на 3★: Boat->(2,0), Boat->(2,2), Boat->(4,2), Boat->(2,2), Boat->(3,3)

### ocean-02

идея: знакомство с плотом: лягушка запрыгивает на плот, течение подвозит её к берегу, дальше журавль и лягушка собирают звёзды

```
##.#E
##**.
##*##
S#r>#
```
Решение на 3★: Frog->(2,0), Frog->(3,2), Crane->(2,2), Crane->(2,1), Frog->(2,3), Frog->(4,3)

### ocean-03

идея: плот везёт журавля: шагни на плот, пока он у берега, течение перевезёт через протоку; дальше звёзды по островку и финиш через плот

```
#.**#
Sr>~#
###*E
```
Решение на 3★: Crane->(1,1), Crane->(2,2), Crane->(3,2), Crane->(3,1), Crane->(3,0), Crane->(4,0)

### ocean-04

идея: плот по расписанию: плот плывёт к причалу; журавль успевает взять звезду и вернуться ровно к его приходу, плот перевозит на остров, лодка по течению с поворотом к финишу

```
##~**v#
##^.#>E
.S^<r##
#*#####
```
Решение на 3★: Crane->(1,0), Crane->(1,1), Crane->(2,1), Crane->(3,2), Crane->(3,3), Crane->(4,3), Boat->(6,2)

### ocean-05

идея: лодка на плоту: лодка причаливает к плоту, течение везёт их вместе за звездой; дальше журавль и лягушка, и снова лодка до финиша

```
##E~.#
####~#
###*w*
S~~~r#
```
Решение на 3★: Boat->(4,0), Crane->(5,1), Frog->(3,1), Crane->(4,1), Boat->(4,3), Boat->(2,3)

### ocean-06

идея: прилив (единственный в мире): клетки прилива меняются каждый ход; журавль идёт по отливу, лодка проходит протоку в полную воду, лягушка прыгает на кувшинку у края

```
####E#
SD>~#P
.**#.w
```
Решение на 3★: Crane->(0,0), Crane->(1,0), Crane->(2,0), Boat->(3,1), Frog->(5,1), Boat->(4,0), Frog->(4,2)

### ocean-07

идея: течение подгоняет плот к лодке: сначала журавль, потом лодка причаливает к подошедшему плоту и едет на нём за звездой; одно решение на 3★

```

```

### ocean-09

идея: встреча с Лесом: хрупкие клетки рушатся за лодкой и лягушкой, течение разворачивает лодку; пройти можно только один раз каждой клеткой
