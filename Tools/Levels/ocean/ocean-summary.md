# Океан: 10 + 3 уровня

Это полный мир «Океан» в `.pbl`, собранный по схеме Леса. Основа — течение и плот. Прилив есть только в уровне 06.

Игрового вида механик Океана пока нет: в Unity эти уровни не импортируются (импорт отклоняет течение и плоты). Все уровни проверены командой `LevelReport check` на правилах по умолчанию, ошибок валидатора нет. Пробные уровни этапа 3 и вердикт по механикам лежат в `probes/`.

| Уровни | Содержание |
| --- | --- |
| 01–03 | Вводные: течение для лодки, плот везёт лягушку, плот и течение вместе. Прощение 50–100 %. |
| 04–07 | Развитие: плот-островок, лодка на плоту, прилив (06), плот, который течение подгоняет к лодке. |
| 08–09 | Встреча с Лесом: кувшинки и листок (08), хрупкие клетки (09). |
| 10 | Финал: все четыре формы, течение и плот. |
| Б1–Б3 | Бонусы: запаса нет, на 3★ ровно 9 ходов, решение единственное. |

Требования штаба и как они выполнены:

- Прощение вводных не ниже 50 %: 50, 100 и 50 %.
- После вводных прощение между соседними уровнями падает не больше чем вдвое: 50 → 33 → 33 → 25 → 20 → 20 → 17 → 14 %.
- Мёртвых клеток 0 во всех 13 уровнях.
- Прилив в одном уровне из трёх разрешённых.
- В каждом уровне решатель подтверждает, что без течения 3★ получаются иначе или не получаются. Плот нужен во всех основных уровнях, кроме 09, и в Б1.

Ограничения, о которых стоит знать:

- Прощение вводных посчитано на малом числе первых ходов (1 из 2, 1 из 1). Это честная метрика, но шагов мало, и в живой игре ощущение может отличаться.
- На плоту реально едут в уровнях 02, 05 и 07. В 03 плот уходит по течению с пути. В 04, 06, 08 и 10 плот стоит островком: течения под ним нет, но без него маршрут другой.
- Финал (5×6) меньше финала Леса (8×8). Большие поля с течением и плотом генератор за отведённое время не находил с нужным прощением. Если финал нужен крупнее, это отдельная доводка.
- Бонусы по 9 ходов, а не по 10, как в Лесу.
- Описания идей в уровнях написаны по маршруту решателя, специально их никто не конструировал.

### ocean-01

идея: знакомство с течением: лодка входит в струю, и течение поворачивает её к звёздам и к финишу, до которого по прямой не доплыть

```
##>E#
##*w.
##w##
S~.##
```
Решение на 3★: Boat->(2,0), Boat->(2,2), Boat->(4,2), Boat->(2,2), Boat->(3,3)

### ocean-02

идея: знакомство с плотом: лягушка запрыгивает на плот, течение подвозит её к берегу, дальше журавль и лягушка собирают звёзды

```
##.#E
##**.
##*##
S#r>#
```
Решение на 3★: Frog->(2,0), Frog->(3,2), Crane->(2,2), Crane->(2,1), Frog->(2,3), Frog->(4,3)

### ocean-03

идея: плот и течение вместе: лодка плывёт по течению за звездой, пока плот уходит по своей струе и освобождает журавлю путь к финишу

```
S###
wrv#
..wE
*.##
```
Решение на 3★: Boat->(0,1), Crane->(0,0), Crane->(0,1), Crane->(1,1), Crane->(2,1), Crane->(3,1)

### ocean-04

идея: течение вдоль края: лодка обходит поле по струе и собирает звёзды; плот стоит островком у берега и меняет маршрут, финиш достаёт лягушка

```
vwr~*
.###~
*..E~
####S
```
Решение на 3★: Boat->(4,3), Boat->(2,3), Boat->(0,2), Crane->(0,1), Crane->(1,1), Frog->(3,1)

### ocean-05

идея: лодка на плоту: лодка причаливает к плоту, течение везёт их вместе за звездой; дальше журавль и лягушка, и снова лодка до финиша

```
##E~.#
####~#
###*w*
S~~~r#
```
Решение на 3★: Boat->(4,0), Crane->(5,1), Frog->(3,1), Crane->(4,1), Boat->(4,3), Boat->(2,3)

### ocean-06

идея: прилив (единственный в мире): клетки прилива меняются каждый ход; журавль идёт по отливу, лодка проходит протоку в полную воду

```
####E#
SD>~#r
.**#.w
```
Решение на 3★: Crane->(0,0), Crane->(1,0), Crane->(2,0), Boat->(3,1), Frog->(5,1), Boat->(4,0), Frog->(4,2)

### ocean-07

идея: течение подгоняет плот к лодке: сначала журавль, потом лодка причаливает к подошедшему плоту и едет на нём за звездой; одно решение на 3★

```
##.#.#
E#.*~#
#r~.~*
#>w>.S
```
Решение на 3★: Crane->(5,1), Boat->(3,1), Boat->(2,0), Frog->(3,2), Crane->(2,2), Frog->(0,2)

### ocean-08

идея: встреча с Лесом: кувшинки тонут за спиной, листок даёт журавлю лишний ход; течение у края уносит лодку к двум звёздам

```
S#####
######
PPP~.#
rw..ww
####E.
```
Решение на 3★: Frog->(0,2), Crane->(1,2), Boat->(0,1), Frog->(2,1), Crane->(3,1), Boat->(5,0), Crane->(4,0)

### ocean-09

идея: встреча с Лесом: хрупкие клетки рушатся за лодкой и лягушкой, течение разворачивает лодку; пройти можно только один раз каждой клеткой

```
S*~.
###~
.#.<
.#*f
~#w#
.#fE
```
Решение на 3★: Crane->(1,5), Boat->(3,5), Boat->(2,3), Crane->(2,2), Frog->(2,0), Boat->(2,2), Crane->(3,2), Frog->(3,0)

### ocean-10

идея: финал: все четыре формы, течение и плот; самолёт, лягушка, лодка и журавль передают друг другу ход по длинной цепочке

```
##.E#
.r###
*.###
#.###
##*w.
#S###
```
Решение на 3★: Plane->(2,1), Frog->(4,1), Boat->(2,1), Plane->(0,3), Crane->(0,4), Crane->(1,4), Plane->(2,5), Crane->(3,5)

### ocean-b1

#~####
#P~*w#

### ocean-b2

### ocean-b3
