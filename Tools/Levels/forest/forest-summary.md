# Бамбуковый лес: 15 уровней

Все уровни проверены командой `LevelReport check`: правила по умолчанию, ошибок валидатора нет.

Требования к подборке:

- Основные уровни 1–12: запас 1–3, флагов качества нет, 1–2 маршрута на 3★, финиш не короче половины маршрута на 3★.
- Бонусные Б1–Б3: запас 0. Бюджет ровно на маршрут, и любой финиш в этот бюджет собирает все три звезды. Маршрут на 3★ у каждого единственный.
- Хрупкие клетки есть в 4 уровнях из 15: 06, 10, 11, 12.

Длина маршрута на 3★ по группам:

| Группа | Уровни | Длина маршрута на 3★ |
| --- | --- | --- |
| Вводные | 1–3 | 6, 5, 4 |
| Развитие | 4–11 | 8, 6, 6, 6, 7, 7, 8, 8 |
| Финал | 12 | 9 |
| Бонус | Б1–Б3 | 10 |

Как получены уровни:

- Уровни 1–3 сделаны вручную.
- Остальные найдены генератором `Tools/LevelSearch` и отобраны вручную.
- Бонусные уровни доведены до нулевого запаса новым режимом генератора `tighten`: он меняет клетки по одной, пока кратчайший финиш не сравняется с бюджетом.
- Неиспользуемые клетки вырезаны, поэтому у карт рваные края. Оформление краёв остаётся за художником.

Что стоит проверить глазами:

- Б2: кувшинки стоят без воды вокруг. По правилам это работает, но выглядит странно. Можно заменить их на обычную землю, если художник против.
- 12, финал: связка из трёх участков описана по маршруту решателя. Отдельно я её не конструировал.
- Листки (08, 10, 11) пока есть только в .pbl. В `LevelData` их нет, нужен импорт в Unity.

### forest-01

идея: журавль ходит на соседнюю клетку; за звездой можно свернуть с дороги и вернуться.

```
##*##
S*.*E
#####
```
Решение на 3★: Crane->(1,1), Crane->(2,1), Crane->(2,2), Crane->(2,1), Crane->(3,1), Crane->(4,1)

### forest-02

идея: лягушка прыгает ровно через клетку, перелетая ямы; короткий путь к финишу пуст, звёзды — на длинном.

```
*#*#*
#####
.###E
#####
S#.#.
```
Решение на 3★: Frog->(0,2), Frog->(0,4), Frog->(2,4), Frog->(4,4), Frog->(4,2)

### forest-03

идея: самолёт летит по диагонали сколько угодно и собирает звёзды по пути; остановиться можно на любой клетке.

```
*###*
#.#.#
##.##
#.#*#
S###E
```
Решение на 3★: Plane->(4,4), Plane->(2,2), Plane->(0,4), Plane->(4,0)

### forest-04

идея: лодка доплывает до первого берега и подбирает звёзды на воде; маршрут по кольцу проток — единственный.

```
######
.~~~~.
~####~
.##E#w
~.w~wS
.~~.~.
```
Решение на 3★: Boat->(1,1), Boat->(5,1), Boat->(5,4), Boat->(0,4), Boat->(0,2), Boat->(0,0), Boat->(3,0), Boat->(3,2)

### forest-05

идея: журавль и лягушка дополняют друг друга: где нельзя шагнуть, прыгай, где нельзя прыгнуть, шагай.

```
E**..
```
