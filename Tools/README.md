# Tools: ядро правил вне Unity

Правила хода Paperbound живут в одном месте — `Assets/Scripts/Core` (сборка `Paperbound.Core`, без UnityEngine).
Ими пользуются игра (`Player`, `BoardPiece`, `Board`), решатель и редактор уровней (`LevelEditorWindow.SolveLevel`).

Здесь лежат проекты, которые компилируют те же исходники обычным dotnet:

- `Paperbound.Core.Tests` — юнит-тесты правил и решателя плюс регрессия по всем уровням из `Assets/Data/Levels`.
- `LevelReport` — отчёт решателя по уровням (финиш, запас бюджета, три звезды, минимум складок, число решений,
  проверка сохранённого в ассете решения).
- `Shared/LevelAssetReader.cs` — чтение `LevelData` (.asset) без Unity.

```bash
# .NET 8 SDK (в облачном контейнере: apt-get install -y dotnet-sdk-8.0)
dotnet test Tools/Paperbound.Core.Tests
dotnet run --project Tools/LevelReport -- Assets/Data/Levels level-report.md
```

`LangVersion` зафиксирован на 9.0, чтобы ядро не использовало синтаксис, которого нет в Unity.

## Правила (RuleSet)

| Флаг | По умолчанию | Смысл |
| --- | --- | --- |
| `SlipperyIce` | да | журавль, зайдя на лёд, едет до первой нелёдяной клетки; лягушка не скользит |
| `BoatCollectsStars` | да | лодка собирает звёзды на воде по пути |
| `PlaneFliesOverWaterAndEmpty` | нет | гипотеза: самолёт пролетает над водой, пустотой и обрушенными клетками |

`RuleSet.Legacy` — поведение до переработки ядра, для сверки старых уровней.

## Что где

- `Rules.GetOptions` — варианты хода формы (с путём и флагом допустимости для подсветки).
- `Rules.ResolveClick` — какой ход означает клик (вода для лодки, первый лёд для журавля).
- `Rules.Apply` — применить ход: новое `GameState` + упорядоченные события для анимации (звёзды, обрушения, гибель, расписания).
- `Rules.Fold` — смена формы, считается складкой.
- `GameState` — полное состояние; история Undo — стек состояний, поэтому расписания и будущие сущности откатываются сами.
- `ScheduleDef` — расписание общего вида (вулкан и источник льда — частные случаи).
- `Solver.Solve` — отчёт по уровню; `Solver.FindShortest` — кратчайший путь до произвольной цели.
- `LevelValidator` — 1 Start, 1 End, 3 звезды, бюджет ≥ 0 (−1 — ошибка), поле до 8×8, корректные расписания.
